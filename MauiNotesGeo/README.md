# 🚀 Заметки с Геолокацией и Камерой

**Мощное MAUI-приложение для создания заметок с фото и геопозицией**

Современное кросс-платформенное приложение на .NET MAUI, где каждая заметка может содержать фотографию и точные координаты места.

---

## ✨ Основные возможности

- 📸 **Добавление фото** через камеру или галерею
- 📍 **Геолокация** — автоматическое определение координат
- 🗺 **Интерактивная карта** (OpenStreetMap) с маркером
- 📋 Красивый список заметок с миниатюрами
- 💾 Хранение в SQLite

---

## 📋 Выполненные задания

### Пара 1
- Создание таблицы `Notes` с полями: `Id`, `Title`, `PhotoPath`, `Latitude`, `Longitude`, `CreatedAt`
- Страница `AddNotePage` с полем заголовка, кнопками Камера/Галерея и превью фото
- Сохранение заметки в SQLite
- Главная страница с `CollectionView`

### Пара 2
- Кнопка **"Прикрепить геометку"**
- Определение координат через `LocationService`
- Сохранение широты и долготы
- Страница `MapPage` с картой
- Отображение иконки 📍 в списке
